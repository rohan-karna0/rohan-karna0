## 🚀 Current Ongoing Projects

### Healthcare RAG System
`Python` `LangChain` `Qdrant` `Ollama` `Streamlit` `FastAPI` · *May 2026 – Present*

- Built an end-to-end Retrieval-Augmented Generation pipeline that ingests trusted medical content (CDC, WHO), chunks and embeds documents, and stores them in Qdrant for semantic search
- Implemented hybrid retrieval with dense embeddings and BM25, plus reranking and citation-backed answers from a local Ollama LLM to reduce hallucinations
- Developed a Streamlit chat interface and FastAPI endpoints for grounded medical Q&A with source attribution

### E-commerce Return Risk Platform
`Python` `FastAPI` `XGBoost` `SHAP` `Streamlit` · *Mar 2026 – Present*

- Built an end-to-end return-risk pipeline on the Olist dataset merging orders, products, reviews, and sellers; predicts return likelihood using tabular, review-text, and listing-photo signals
- Trained XGBoost models with stratified cross-validation and class-imbalance handling; used SHAP so sellers can see which features drive each risk score
- Estimated causal effects of seller practices (e.g. size charts) via propensity score matching; exposed scores and explanations through FastAPI and a Streamlit dashboard
